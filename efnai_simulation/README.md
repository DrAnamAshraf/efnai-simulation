## What This Code Does

This repository contains the complete simulation code for the internal consistency check described in Section 4 of the paper. It:

1. Generates simulated functional connectivity (FC) data calibrated to published ADHD-200 statistical parameters (n=973, 8 sites, AAL-116 parcellation)
2. Extracts 37 fully specified graph features (Table 3 of the paper)
3. Trains a Graph Feature Classifier (GFC: gradient boosting) and three reference classifiers
4. Evaluates using 10-fold stratified cross-validation with bootstrap confidence intervals
5. Runs a federated site-held-out evaluation across 8 simulated sites
6. Produces Figures 1 and 2 and all results in Tables 4 and 5 of the paper

**This simulation does NOT implement the proposed GAT-GNN encoder, EEG encoder, alignment module, or federated DP training.** It confirms only that the feature specification and evaluation pipeline are internally consistent.

## Reproducing the Paper Results

### Requirements
- Python 3.9+
- See `requirements.txt`

### Installation
```bash
pip install -r requirements.txt
```

### Run
```bash
python run_all.py
```

This produces:
- `results/results.json` — all numerical results (Table 4, Table 5)
- `results/figure2_sanity_check.png` — Figure 2
- `results/validation_results.csv` — raw fold-level results

### Random Seed
All results use `numpy.random.seed(42)`. This seed is fixed throughout and produces the exact numbers reported in the paper.

## Key Parameters (Section 4.1 of paper)

| Parameter | Value | Source |
|-----------|-------|--------|
| n_subjects | 973 | Bellec et al. (2017) |
| n_ADHD | 491 | Bellec et al. (2017) |
| n_controls | 482 | Bellec et al. (2017) |
| n_sites | 8 | ADHD-200 Consortium |
| n_ROIs | 116 | AAL-116 parcellation |
| DMN effect size (Cohen d) | 0.42 | Zhao et al. (2022); Wang M. et al. (2023) |
| Effect size range | 0.32–0.48 | Firouzi et al. (2024) |
| Base noise sigma | 1.8 | Calibrated to published variance |
| Random seed | 42 | Fixed |
